## Еще не выполнено: нужен реальный MAX

`MAX_BOT_TOKEN`, `MAX_WEBHOOK_SECRET` и реальный ID администратора в среде не заданы. Внешний HTTPS-домен и сертификат webhook не предоставлены. Поэтому не проверены:

1. Проверка реального токена `GET /me`, создание подписки `/subscriptions` и доставка событий от реального MAX.
2. Отображение кнопок и callback-уведомлений в разных клиентах MAX.
3. Реальная регистрация двух пользователей, одобрение администратором и использование кнопок сотрудником.
4. Выдаваемый именно этому боту HTTPS-хост загрузки, фактическая обработка CSV MAX и открытие вложения в Excel. Хост необходимо получить командой `upload-host`, разрешить точечно в `MAX_UPLOAD_ALLOWED_HOSTS` и сетевой политике.
5. Производственные ограничения частоты MAX и поведение при отключении/восстановлении внешнего сервиса под реальной нагрузкой. Автоматические тесты используют подмененный HTTP-транспорт для этих ответов.

Порядок подключения: заполнить `.env` → запустить Compose → настроить внешний HTTPS → `check-max` → `subscribe` → первым запустить бота администратором → зарегистрировать сотрудника → выполнить смену с перерывом → отправить/одобрить исправление → получить текстовый отчет и CSV. Полные команды находятся в README.
